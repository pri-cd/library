# 📚 Library Dashboard

A clean, lightweight library dashboard for managing your reading list.

Add books, track whether you have read them, and remove entries with a simple, easy-to-use interface.

## ✨ Features

- Add books with a title, author, and page count
- View all books in a responsive card grid
- Mark books as read
- Delete books from your list
- Uses a modern, colorful interface
- No frameworks or external dependencies
